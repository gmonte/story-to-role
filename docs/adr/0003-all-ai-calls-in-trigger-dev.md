# Every AI call runs in Trigger.dev, including interview turns

All AI processing runs as Trigger.dev tasks that stream progress and tokens to the client through Trigger.dev Realtime and save results to Postgres, never inside the web request that the chat sends. Resume generation with review rounds takes minutes and would exceed Vercel function limits; running everything the same way gives retries, durable progress (a closed tab loses nothing) and one place for cost accounting. We accepted that starting a task adds latency to each interview turn; this must be measured in the first prototype, keeping workers warm if needed. Tasks receive only IDs and load content inside the task, so no career content reaches Trigger.dev's logs.
