# Each opening has its own agent, on chat.agent like the profile's and the documents'

The opening page gets a fixed right column — Agent · Fit · Application — in every step (workspace spec, “The opening page”). In the Resume and Cover letter steps the agent is the document's (ADR 0009); in the Opening, Fit and Application steps it is the **opening agent**: one conversation per opening, on Trigger.dev `chat.agent`, sharing the profile and document agents' plumbing and privacy model (transcript encrypted in our tables, no client data in traces, 7-day session deadline, ownership checked on our server, charged per message).

It knows the opening (description, extracted requirements, warnings), the fit check with its verdicts and the profile passages behind them, this opening's gap answers, the approved company facts, the application's state, and the published profile (index plus a tool to read a part). It helps the user understand the fit, answer gap questions in conversation (an answer becomes the same gap answer the Fit step records, with the user's confirmation), prepare for the letter's motivation, and decide next steps. It never spends credits on the user's behalf (generating, researching, checking again stay buttons the user presses), never changes the profile directly (facts go to the profile as suggestions, as everywhere), and invents nothing.
